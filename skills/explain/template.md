# Explanation Template

Use this structure for every explanation:

### 1. High-level Purpose
One or two sentences explaining what this code is responsible for.
List explicitly what the inputs and outputs are of the code.

### 2. Key Components
- List the main functions, classes, or sections
- Briefly describe what each one does

### 3. Execution Flow
Step-by-step explanation of how the code runs (from entry point → main logic → outputs/side effects).

### 4. Important Details
- Notable design decisions
- Edge cases handled
- Dependencies or external interactions
- Anything non-obvious

### 5. Observations (not fixed)
List any potential bugs, code smells, unclear parts, or possible improvements you noticed.  
Do **not** fix them — just note them.
